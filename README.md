# BSERC GenAI Internship — Week 2 Projects

This repository contains my complete submission for **Week 2 Projects** of the Bharat Space Education Research Centre (BSERC) GenAI Internship.

---

## 📁 Repository Structure & Projects Built

### 🌐 Section A: Web Tools
* **`Project1_PDFStudio/`** — **Offline PDF Studio**
  * Single-page web tool allowing PDF merge, split, reorder, text redacting, watermarking, image-to-PDF conversion, and compression completely offline.
* **`Project3_ResumeBuilder/`** — **Live A4 Resume Builder**
  * Form-driven live preview builder supporting 3 dynamic templates, drag-and-drop sections, and clean A4 print export.

---

### 📱 Section B: Phone Apps & Games
* **`Project7_BillBook/`** — **Offline Store Billing App**
  * Retail invoice generator with dynamic item pricing, instant UPI payment QR code rendering, and offline local transaction storage.
* **`Project8_AutoRally/`** — **2D Auto-Rickshaw Racing Game**
  * 3-lap mobile HTML5 canvas game with touch/keyboard steering controls, collectible coins, nitro boosts, synthesised web audio effects, and high scores.

---

### 🌐 Section C: Chrome Extensions
* **`Project9_YTFocusBoard/`** — **YouTube Focus Board Extension**
  * Manifest V3 extension that strips distraction elements (Shorts, comments, recommendations), enforces a time-gated access prompt, and includes timestamped video note-taking.
* **`Project10_JobClipper/`** — **Job Clipper & Kanban Tracker**
  * One-click job details scraper that automatically clips role titles, company names, and URLs to an interactive Kanban board with CSV export.

---

### 🎨 Section D: Video, Skills and Design
* **`Project16_AgentSkill/`** — **`/viva` AI Examiner Skill**
  * Custom reusable AI skill prompt definition (`SKILL.md`) that acts as an interactive technical examiner, prompting 5 progressive viva questions and scoring performance.
* **`Project17_DesignRedesign/`** — **Symposium Page Redesign**
  * Before-and-after UI comparison showcasing identical copy transformed from raw unstyled HTML (`before.html`) to modern glassmorphic responsive UI (`after.html`) using specialized design skills.

---

* **`prompts.md`** — **Complete AI Prompt Log**
  * Chronological log detailing every prompt used across ChatGPT, Claude, and Gemini to generate and refine all projects.

---

## 💻 How to Run

1. **Web Tools & Games:** Open any `index.html` file inside the respective project folders directly in any web browser.
2. **Chrome Extensions:** Open `chrome://extensions` in Google Chrome, enable **Developer mode**, click **Load unpacked**, and select the folder (`Project9_YTFocusBoard` or `Project10_JobClipper`).
